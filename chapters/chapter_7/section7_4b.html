Solution

First, it looks like 𝑒𝑥 is everywhere, so we will do a quick 𝑢-substitution with 𝑢=𝑒𝑥. Then d𝑢=𝑒𝑥d𝑥

∫3𝑒2𝑥−5𝑒3𝑥(3𝑒𝑥−1)(𝑒𝑥−1)2d𝑥=∫3𝑒𝑥−5𝑒2𝑥(3𝑒𝑥−1)(𝑒𝑥−1)2𝑒𝑥d𝑥=∫3𝑢−5𝑢2(3𝑢−1)(𝑢−1)2d𝑢

Now, this integral needs a partial fraction decomposition. The denominator is already factored into all linear terms so the form of the partial fractions is

3𝑢−5𝑢2(3𝑢−1)(𝑢−1)2=𝐴3𝑢−1+𝐵𝑢−1+𝐶(𝑢−1)2

Multiplying everything by the common denominator

3𝑢−5𝑢2(3𝑢−1)(𝑢−1)2((3𝑢−1)(𝑢−1)2)=(𝐴3𝑢−1+𝐵𝑢−1+𝐶(𝑢−1)2)((3𝑢−1)(𝑢−1)2)3𝑢−5𝑢2=𝐴(𝑢−1)2+𝐵(𝑢−1)(3𝑢−1)+𝐶(3𝑢−1)

We can find 𝐴,𝐶 easily by plugging in values 𝑢=1,𝑢=13 but will have to deal with 𝐵 another way. Then, for 𝑢=1

3(1)−5(1)2=𝐴((1)−1)2+𝐵((1)−1)(3(1)−1)+𝐶(3(1)−1)−2=2𝐶

so 𝐶=−1. Then

3(13)−5(13)2=𝐴((13)−1)2+𝐵((13)−1)(3(13)−1)+𝐶(3(13)−1)49=49𝐴

so 𝐴=1. Then plugging in 𝐴,𝐶 we have

3𝑢−5𝑢2=(𝑢−1)2+𝐵(𝑢−1)(3𝑢−1)−(3𝑢−1)

Since we only need to find one of the coefficients still, we can plug in any value for 𝑢 we haven’t used here and solve for 𝐵. Let’s do 𝑢=−1. Then,

3(−1)−5(−1)2=((−1)−1)2+𝐵((−1)−1)(3(−1)−1)−(3(−1)−1)−8=4+𝐵(−2)(−4)−(−4)−8=4+8𝐵+4−16=8𝐵

so 𝐵=−2. Then, the integrand becomes

∫3𝑒2𝑥−5𝑒3𝑥(3𝑒𝑥−1)(𝑒𝑥−1)2d𝑥=∫𝐴3𝑢−1+𝐵𝑢−1+𝐶(𝑢−1)2d𝑢=∫13𝑢−1−21𝑢−1−1(𝑢−1)2d𝑢=∫13𝑢−1d𝑢−2∫1𝑢−1d𝑢−∫1(𝑢−1)2d𝑢

We can solve each of these new integrals with a small substitution. First, let 𝑤=3𝑢−1 then d𝑤=3d𝑢 and so

∫13𝑢−1d𝑢=13∫1𝑤d𝑤=13ln|𝑤|=13ln|3𝑢−1|=13ln|3𝑒𝑥−1|,

where we might as well get back to 𝑥 while we are here. Then with 𝑦=𝑢−1 so d𝑦=d𝑢 the second integral becomes

−2∫1𝑢−1d𝑢=−2∫1𝑦d𝑦=−2ln|𝑦|=−2ln|𝑢−1|=−2ln|𝑒𝑥−1|.

Lastly, with 𝑧=𝑢−1 so d𝑧=d𝑢 the last integral becomes

−∫1(𝑢−1)2=−∫𝑧−2d𝑧=−1−1𝑧−1=1𝑧=1𝑢−1=1𝑒𝑥−1

Altogether our final answer is

∫3𝑒2𝑥−5𝑒3𝑥(3𝑒𝑥−1)(𝑒𝑥−1)2d𝑥=13ln|3𝑒𝑥−1|−2ln|𝑒𝑥−1|+1𝑒𝑥−1+𝐶.

There are no extra considerations needed for the bounds of these integrals. If you end up needing a substitution, change the bounds accordingly and so on.

11. Sequences and Series

11.8. Power Series

11.8 Learning Objectives

  • Identify power series
  • Use previous techniques to determine whether the series converges or diverges
  • Understand how the center and coefficients affect the convergence of power series
  • Identify the radius of convergence for series that converge on an interval

11.8.1. Motivation

Do the following series converge or diverge? How do you know?

  1. ∑𝑛=0∞(23)𝑛
    converges because it is geometric with 𝑎=1 and |𝑟|=23<1
  2. ∑𝑛=0∞(−4)𝑛
    diverges because it is geometric with 𝑎=1 and |𝑟|=4>1
  3. ∑𝑛=0∞44(1100)𝑛
    converges because it is geometric with 𝑎=44 and |𝑟|=1100<1

Observe that 𝑟 is changing in these scenarios, so we can represent these with a variable 𝑥…

11.8.2. Power Series

Note

  • Notice 𝑎 does not have a dependency on 𝑛, so it is the same for every term in the series.
  • Here 𝑐𝑛 depends on which term in the series, 𝑛 we are currently adding, so 𝑐0 may be different from 𝑐1 etc.

  • You could write this as

    ∑𝑛=1∞𝑐𝑛𝑥𝑛−1

    if you like, but we won’t. We will just start these at 0.

  • Power series is named because the terms are all some number times a power of 𝑥.

  • Examples of power series

    • ∑𝑛=1∞𝑥𝑛𝑛=𝑥+𝑥22+𝑥33+𝑥44+… is a power series where the first coefficient 𝑐0=0, the center 𝑎=0, and 𝑐𝑛=1𝑛 for 𝑛≥1.
    • ∑𝑛=0∞3(𝑥−1)𝑛=3+3(𝑥−1)+3(𝑥−1)2+… is a power series where 𝑐𝑛=3 for all 𝑛≥0 and center 𝑎=1. (The sum started at 0 this time, like we expected, so we did not have to write the first coeff was 0 like the last example)
    • ∑𝑛=0∞(𝑛+1)!𝑥𝑛=1+2𝑥+6𝑥2+24𝑥3+… is a power series where 𝑐𝑛=(𝑛+1)! and center 𝑎=0.

  • What affects the convergence or divergence of this series?

    • The value of 𝑥 and the values of the sequence (𝑐𝑛)𝑛=1∞ impacts the convergence or divergence. 𝑥 is just a number, but if 𝑐𝑛 depends on 𝑛 and is not just a number, then the series cannot be considered like geometric.

  • If 𝑥=0, does the series ∑𝑛=0∞𝑐𝑛𝑥𝑛 converge?

    • If 𝑥=0, we have ∑𝑛=0∞𝑐𝑛𝑥𝑛=𝑐0+𝑐1⋅0+0+0+0+0+…=𝑐0 so the series always converges when 𝑥=0.

  • Similarly, if we have the series ∑𝑛=0∞𝑐𝑛(𝑥−𝑎)𝑛, it always converges for 𝑥=𝑎. This is why 𝑎 is called the center of the series.

Note

For

𝑓(𝑥)=∑𝑛=0∞𝑐𝑛(𝑥−𝑎)𝑛,

𝑥=𝑎 is always in the domain of 𝑓(𝑥).

One effective way to find the values of 𝑥 where a power series converges is with the Ratio Test. This will be a common approach when determining when (what values of 𝑥) power series converge.

Solution

By ratio test, if we want the series to converge we would have

𝐿=lim𝑛→∞|(−1)𝑛+1𝑥𝑛+1(−1)𝑛𝑥𝑛|=lim𝑛→∞|𝑥|=|𝑥|

Ratio test says that when 𝐿<1 we have convergence, 𝐿>1 divergence, and it is inconclusive when 𝐿=1. So we can start to build up when this series converges. When 𝐿=|𝑥|>1 it diverges, when 𝐿=|𝑥|<1 it converges, and when 𝐿=|𝑥|=1 we have to use a different test.

|𝑥|=1 means 𝑥=−1,1. So, checking when 𝑥=1 the series is equivalent to ∑𝑛=0∞(−1)𝑛 which diverges by the Divergence Test since lim𝑛→∞(−1)𝑛 diverges.

Checking when 𝑥=−1, the series is equivalent to

∑𝑛=0∞(−1)𝑛(−1)𝑛=∑𝑛=0∞(−1)2𝑛=∑𝑛=0∞1𝑛=∑𝑛=0∞1

by exponent rules. Also by the divergence test, lim𝑛→∞1=1≠0, so the series diverges when 𝑥=−1.

Therefore, the power series converges exactly when 𝑥 is in (−1,1).

In this example, (−1,1) is called the interval of convergence of the power series.

Solution

We will start with the ratio test,

𝐿=lim𝑛→∞|(2𝑥−3)𝑛+1(𝑛+1)!⋅𝑛!(2𝑥−3)𝑛|=lim𝑛→∞|2𝑥−3|𝑛+1

For any value of 𝑥, the limit as 𝑛→∞ makes this limit 𝐿=0. Therefore, this series converges for all 𝑥. So, the radius of convergence is 𝑟=∞ and the interval of convergence is (−∞,∞).

Note

Say in the above example, that the radius was not 𝑅=∞, but 𝑅=5. We would then need to find the center of the power series in order to determine the interval of convergence. Because of the (2𝑥−3) it is a little trickier, but we set this equal to 0 and solve for 𝑎:

2𝑎−3=0⇒2𝑎=3⇒𝑎=32

The center would be 32, and the interval would start as (32−5,32+5). Then we would have to test each end point separately.

We will see this process in the next example.

Solution

We will once again start with the ratio test,

𝐿=lim𝑛→∞|(𝑥−1)𝑛+15𝑛+1((𝑛+1)+1)⋅5𝑛(𝑛+1)(𝑥−1)𝑛|=lim𝑛→∞|𝑥−1|𝑛+15(𝑛+2)=15|𝑥−1|

This converges when 𝐿<1, or when

15|𝑥−1|<1⇒|𝑥−1|<5

Thus, the radius of convergence is 𝑅=5. Since this power series is centered at 𝑥=1, then the end points of the interval are 𝑥=−4, and 𝑥=6. We need to check these values separately.

When 𝑥=−4, the series is

𝑓(−4)=∑𝑛=0∞(−4−1)𝑛5𝑛(𝑛+1)=∑𝑛=0∞(−1)𝑛(5)𝑛5𝑛(𝑛+1)=∑𝑛=0∞(−1)𝑛(𝑛+1)

Because this is an alternating series, we can apply the alternating series test. Notice 1𝑛+1 is decreasing and lim𝑛→∞1𝑛+1=0, so by the alternating series test, ∑𝑛=0∞(−1)𝑛(𝑛+1) converges, so −4 is in the domain of 𝑓.

When 𝑥=6, the series is

𝑓(6)=∑𝑛=0∞(6−1)𝑛5𝑛(𝑛+1)=∑𝑛=0∞(5)𝑛5𝑛(𝑛+1)=∑𝑛=0∞1(𝑛+1)

Let 𝑏𝑛=1𝑛 and 𝑎𝑛=1𝑛+1, both have positive terms for 𝑛>1, then

lim𝑛→∞𝑏𝑛𝑎𝑛=lim𝑛→∞1𝑛1𝑛+1=lim𝑛→∞𝑛+1𝑛=1>0✓

By limit comparison test, since ∑𝑎𝑛 diverges (harmonic series), so too does ∑1𝑛+1. Then, 𝑥=6 is not in the domain of 𝑓.

Finally, putting everything together, the interval of convergence is [−4,6).

Note

The general process for doing this is

  1. Apply a series convergence test to find when the power series converges, almost always ratio test.
  2. Get the inequality down to |𝑥−𝑎|<𝑅, potentially dividing by any constant in front of 𝑥 to do so. Then this is the radius of convergence 𝑅.
  3. Find left and right endpoints 𝑎−𝑅, and 𝑎+𝑅.
  4. Plug in the left and right endpoints separately, and use other series convergence tests to figure out if the resulting series converges or diverges.
  5. Write the interval of convergence, including the endpoint if the respective series converged or excluding it if it diverged.

  • We used ratio test and other series convergence tests to determine the interval of convergence (𝑥 values when the series converges) and radius of convergence.

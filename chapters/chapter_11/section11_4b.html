11.4.2. Limit Comparison Test

Solution

Always checking the divergence test at the start, we can confirm the terms of the series go to zero, lim𝑛→∞12𝑛−1=0 so the divergence test is inconclusive.

Then, we can see that 12𝑛−1 is fairly similar to 12𝑛 which we know converges because ∑𝑛=1∞12𝑛=∑𝑛=1∞(12)𝑛 is a geometric series with 𝑟=12<1.

Next, if we want to use direct comparison test to show convergence, then we would need

12𝑛−1<12𝑛in other words 2𝑛−1>2𝑛

which is false! So we cannot use direct comparison test.

We can use limit comparison test, however: let 𝑏𝑛=12𝑛 and 𝑎𝑛=12𝑛−1 then

lim𝑛→∞𝑎𝑛𝑏𝑛=lim𝑛→∞12𝑛−112𝑛=lim𝑛→∞2𝑛2𝑛−1=lim𝑛→∞11−12𝑛=11−0=1

since 1 is constant, then by the limit comparison test the series ∑𝑛=1∞12𝑛−1 converges.

Solution

We start by deciding which test to use:

  • divergence test is inconclusive since lim𝑛→∞2𝑛2+3𝑛5+𝑛5=0 (exercise: work out this limit to show this step and convince yourself)
  • this is not something like a telescoping series where the partial sums are easy to simplify and find the limit of, so we skip that idea
  • this is not a geometric series, like ∑𝑛=1∞𝑎𝑟𝑛, so geometric series test does not apply
  • this is not a 𝑝-series, like ∑𝑛=1∞1𝑛𝑝, so 𝑝-series test does not apply
  • this is not something we really want to integrate, so we will avoid this test for now
  • this is a fairly complicated expression to have as the terms in the series, if we could “ignore” some of the terms and simplify it would actually be sort of like a 𝑝-series… so let’s compare this to something a little simpler.

In order to figure out which series to compare this to, we want a series that grows at the same rate as the given series. Comparing the degrees of the numberator and denominator, we can compare this series to ∑𝑛=1∞𝑛2𝑛5=∑𝑛=1∞1𝑛, which diverges by the 𝑝 series test, since 𝑝=05<1. We can either try using direct comparison test (we would have to show that 2𝑛2+3𝑛5+𝑛5≥𝑛2𝑛5, which doesn’t sound easy) or the limit comparison test.

Using limit comparison test, let 𝑎𝑛=2𝑛2+3𝑛5+𝑛5 and 𝑏𝑛=𝑛2𝑛5. Note, 𝑎𝑛 and 𝑏𝑛 have positive terms since everything involved is addition and powers of 𝑛. Now that we checked the conditions for limit comparison test, let’s compute the limit

lim𝑛→∞𝑎𝑛𝑏𝑛=lim𝑛→∞2𝑛2+3𝑛5+𝑛5𝑛2𝑛5=lim𝑛→∞2𝑛2+3𝑛5+𝑛5(𝑛5𝑛2)=lim𝑛→∞2𝑛2+3𝑛5+𝑛5(1𝑛21𝑛5)=lim𝑛→∞2+3𝑛5𝑛5+1=2+lim𝑛→∞3𝑛lim𝑛→∞5𝑛5+1=21=2

Since 2 is a constant, then we know the series ∑𝑛=1∞𝑎𝑛 and ∑𝑛=1∞𝑏𝑛 either both diverge or both converge. Since ∑𝑛=1∞𝑏𝑛 diverges with 𝑝-series test, then ∑𝑛=1∞𝑎𝑛 also diverges by the limit comparison test.

11.10. Taylor and Maclaurin Series

11.10 Learning Objectives

  • Find the Taylor Series Expansion of a function
  • Find the Maclaurin Series Expansion of a function
  • Find the function represented by the Taylor or Maclaurin Series
  • Use known Maclaurin Series Expansion of functions to describe complicated functions

11.10.1. Motivation: Linearization of a function

Recall the linearization of a function

  • The idea behind linearization is to come up with a simple function (a line 𝐿) that matches 𝑓 in function value and first derivative.

  • What’s better than matching the function in function value and first derivative at 𝑥=𝑎?

    • Matching the function in value, first derivative, and second derivative at 𝑥=𝑎.

  • What’s better than matching the function in value, first derivative, and second derivative at 𝑥=𝑎?

    • Matching the function in value, first derivative, second derivative, and third derivative at 𝑥=𝑎…
  • Then we build up from there! Going one more degree at a time, matching one extra derivative at 𝑥=𝑎 each term!

11.10.2. Taylor Series and Maclaurin Series

We have been able to write the power series of some functions using algebraic manipulations to line it up with 11−𝑢 type things. However, we may want to represent other functions with power series.

Suppose that 𝑓 can be represented with a power series. Then,

𝑓(𝑥)=∑𝑛=0∞𝑐𝑛(𝑥−𝑎)𝑛=𝑐0+𝑐1(𝑥−𝑎)+𝑐2(𝑥−𝑎)2+𝑐3(𝑥−𝑎)3+𝑐4(𝑥−𝑎)4+…

We already know that when we evaluate this at 𝑥=𝑎 we get

𝑓(𝑎)=𝑐0

Now, taking the element-wise derivative we see that

𝑓′(𝑥)=𝑐1+2⋅𝑐2(𝑥−𝑎)+3⋅𝑐3(𝑥−𝑎)2+4⋅𝑐4(𝑥−𝑎)3+… so 𝑓′(𝑎)=𝑐1

Taking another derivative we see

𝑓″(𝑥)=2⋅1⋅𝑐2+3⋅2⋅𝑐3(𝑥−𝑎)+4⋅3⋅𝑐4(𝑥−𝑎)2+… so 𝑓′(𝑎)=2𝑐1 or 𝑐1=𝑓′(𝑎)2

Taking another derivative we see that

𝑓‴(𝑥)=3⋅2⋅1⋅𝑐3+4⋅3⋅2⋅𝑐4(𝑥−𝑎)+… so 𝑓‴(𝑎)=3!𝑐3 or 𝑐3=𝑓‴(𝑎)3!

Doing one more to really see the pattern,

𝑓(4)(𝑥)=4⋅3⋅2⋅1⋅𝑐4+5⋅4⋅3⋅2⋅𝑐5(𝑥−𝑎)+… so 𝑓(4)(𝑎)=4!𝑐4 or 𝑐4=𝑓(4)(𝑎)4!

In general, the 𝑛th coefficient must be

𝑐𝑛=𝑓(𝑛)(𝑎)𝑛!

Note

Note that we define 0!=1 to make this true when 𝑛=0 as well.

Side note: You can also justify this using another application of factorials: In combinatorics, the number of ways to arrange 𝑛 items in a list is 𝑛!. If you think about having 0 items to arrange in a list, there is only 1 way to do this, by not putting anything. So 0≠1 makes sense “physically”.

Note

  • Note, this theorem does not say when a function has a power series representation.
  • Notation: Recall that 𝑓(𝑛)(𝑥) is the 𝑛th derivative of 𝑓(𝑥), and the parentheses are an important part of this notation. Use this for discussing more than the third or fourth derivative (𝑓′(𝑥),𝑓″(𝑥),𝑓‴(𝑥) are reasonable…). Without the parentheses, 𝑓𝑛(𝑥) is an exponent, meaning 𝑓𝑛(𝑥)=(𝑓(𝑥))⋅(𝑓(𝑥))⋅(𝑓(𝑥))⋅(𝑓(𝑥))…⋅(𝑓(𝑥))=(𝑓(𝑥))𝑛

This series is named after Brook Taylor, who wrote a paper using Taylor Series in 1715, but the importance of it wasn’t noticed until 1772 when Lagrange stumbled across it.

This series is named after Colin Maclaurin, who did a lot of important mathematics using a specialized form of Taylor’s series (at 𝑎=0). I had fun reading his Wikipedia page, and learning that we have already seen another result of Maclaurin’s! And that is Simpson’s Rule! (behind the scenes Simpson’s Rule comes from integrating a truncated Maclaurin series to approximate the integral!) Also, Maclaurin was a child prodigy who held the record for youngest math professor for centuries until Alia Sabur became a university professor when she was only 18 years old!

Solution

We start these problems by finding the first few derivatives evaluated at the center, and try to write a pattern. Note 𝑎=0 for Maclaurin series, and we have

𝑓(𝑥)=𝑒𝑥,𝑓(0)=𝑒0=1𝑓′(𝑥)=𝑒𝑥,𝑓′(0)=𝑒0=1𝑓″(𝑥)=𝑒𝑥,𝑓″(0)=𝑒0=1⋮𝑓(𝑛)(0)=1 for all 𝑛

Then we plug the derivatives into

𝑓(𝑥)=∑𝑛=0∞𝑓(𝑛)(𝑎)𝑛!𝑥𝑛=∑𝑛=0∞1𝑛!𝑥𝑛𝑒𝑥=∑𝑛=0∞𝑥𝑛𝑛!

Now, we find the interval of convergence. By ratio test,

𝐿=lim𝑛→∞|𝑥𝑛+1(𝑛+1)!⋅𝑛!𝑥𝑛|=lim𝑛→∞|𝑥𝑛𝑥(𝑛+1)𝑛!⋅𝑛!𝑥𝑛|=lim𝑛→∞|𝑥|𝑛+1=0

So the series converges for all 𝑥 values, so the radius of convergence is 𝑅=∞ and the interval of convergence is (−∞,∞).

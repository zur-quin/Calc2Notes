11.4. Comparison Tests for Series

11.4 Learning Objectives

  • Determine when it is appropriate to use a comparison test
  • Determine an appropriate series to compare a given series to
  • Know when and how to use direct comparison and limit comparison tests.

11.4.1. Direct Comparison Test

This series is extremely similar to ∑𝑛=2∞1𝑛, which we know diverges. In fact, thinking about graph transformations, 1𝑥−1 is just 1𝑥 shifted one space to the right.

Because ∑𝑛=2∞1𝑛 diverges, we expect that ∑𝑛=1∞1𝑛−1 also diverges, since the only difference is the −1 in the denominator… let’s look at a picture

We can observe that 1𝑥<1𝑥−1 for all 𝑥>0, so for all 𝑛≥1 we have

1𝑛<1𝑛−1∑𝑛=2∞1𝑛≤∑𝑛=2∞1𝑛−1∞≤∑𝑛=2∞1𝑛−1

so ∑𝑛=2∞1𝑛−1 diverges since ∑𝑛=2∞1𝑛 diverges.

Note

In this theorem, we have a series ∑𝑛=1∞𝑎𝑛 with positive terms that we wish to talk about the convergence or divergence of. We make an educated guess on if it converges or diverges, and find another series ∑𝑛=1∞𝑏𝑛 with positive terms either above or below the original, and hope that other series is easier to analyze the convergence of.

Note

The 𝑛≥𝑁 part of all these series convergence tests can be read as “eventually the series behaves this way…”

In the above theorem, it only matters that eventually we have 𝑎𝑛≤𝑏𝑛 (or 𝑎𝑛≥𝑏𝑛). The first few terms before 𝑁 can only contribute a finite amount to the series, and don’t end up mattering in the long run of the sum.

Solution

Let 𝑎𝑛=2𝑛𝑛+6𝑛. Doing a quick check of the divergence test (exercise: check the divergence test is inconclusive yourself, you will need h’Hosptial’s rule and to review exponent rules and exponential derivatives!) we see that lim𝑛→∞𝑎𝑛=0, so the series does not obviously diverge. Then we have to use another one of the tests.

Now we see that this series is very similar to ∑𝑛=1∞2𝑛6𝑛 except it differes by the +𝑛 in the denominator. Importantly,

∑𝑛=1∞2𝑛6𝑛=∑𝑛=1∞(13)𝑛

converges by the Geometric Series test, since 𝑟=13<1.

Now, we have to check the rest of the conditions of the comparison test: all the terms need to be positive and for 𝑛≥1 we have that both 2𝑛𝑛+6𝑛 and 2𝑛6𝑛 are positive.

Lastly we need to show that the series we are comparing to has terms, 𝑏𝑛≥𝑎𝑛, where 𝑎𝑛 are the terms in the original. Notice that if we want

2𝑛𝑛+6𝑛<2𝑛6𝑛then we must also have 1𝑛+6𝑛<16𝑛in which case we also would have 𝑛+6𝑛>6𝑛which is the case if 𝑛>0.

Fortunately this is true, we have 𝑛≥1>0 for all terms in this series (𝑁=0).

So, by the comparison test the series ∑𝑛=1∞2𝑛𝑛+6𝑛 converges.

Note

  • We don’t have to check the divergence test is inconclusive for all of these, but if the divergence test works and shows something is divergent, it is a really quick and easy solution. Essentially, we don’t want to miss any easy ways out in this process so it is good to at least think about before continuing on with the problem.

  • A complete solution to determining a series converges or diverges has the following “rubric”:

    • Did the problem solver identify the right test to use?
    • Did the problem solver check all the hypotheses for the test, showing enough detail for each?
    • Did the problem solver write a conclusion about the convergence of the series including a citation stating which test they used?

  • Note these problems need more writing than a lot of other math up to this point, you should have a few complete sentences in a solution.

Solution

With a quick limit, the divergence test is inconclusive:

lim𝑛→∞cos2(𝑛)1+𝑛5 behaves like a finite number divided by a very large number so =0

Now we notice that this series is similar to ∑𝑛=1∞1𝑛5, which converges by the 𝑝-series test. We just have to relate the original series to this one

𝑎𝑛=cos2(𝑛)1+𝑛5≤11+𝑛5<1𝑛5=𝑏𝑛

(in the first step above, the denominator got bigger going from cos2(𝑛) to 1, then in the second step the denominator got smaller which made the entire fraction larger)

Lastly, for direct comparison test to work, the terms in both series must be positive. Notice that 1𝑛5 is positive for 𝑛≥1 and cos2(𝑛)≥0 since it is a number between −1 and 1 that is squared.

Then, by the direct comparison test, ∑𝑛=1∞cos2(𝑛)1+𝑛5 also converges.

Warning

Can we apply the Direct Comparison Test to the series ∑𝑛=2∞1𝑛2−1?

This series is similar to ∑𝑛=2∞1𝑛2, which converges by the 𝑝-series test, so we would expect the original series to converge. However, since

𝑛2−1<𝑛2 for 𝑛≥2we have 1𝑛2−1>1𝑛2

and so our convergent series we want to compare to is below the original! So, the direct comparison test does not work.

We will build up a tool to use on these types of series in the next part of 11.4.

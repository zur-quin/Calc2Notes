11.6.2. Root Test

The idea behind this convergence test is that if |𝑎𝑛|𝑛 converges to 𝐿, and 𝐿<1, then we have ∑𝑛=1∞𝐿𝑛 is a convergent geometric series because |𝐿|<1. Essentially, ∑𝑛=1∞𝑎𝑛 grows at about the same rate as ∑𝑛=1∞. The Root Test just lets us look at more complicated exponentially-based series by only considering the bas of the exponential expression.

Note

The Ratio Test is inconclusive if and only if the Root Test is inconclusive. If one of these tests is inconclusive, it will never be worth your time to try to other. Choose a different test.

Why might we prefer to use the Ratio Test or Root Test over some of the other tests that we have learned?

What are some clues that we should or should not use these tests?

  • If a series has the entire sequence to the power of 𝑛, then the Root Test may be helpful, especially if it is not a standard geometric series or quickly comparable to a geometric series.
  • If a series has factorials, or a combination of various things (e.g. factorials, exponentials, algebraic terms), then the Ratio Test is the best option (and sometimes the only option!)
  • Bother the Root Test adn Ratio Test will be inconclusive for purely algebraic series, like ∑𝑛=1∞𝑛+𝑛5𝑛2+2. Instead always use a comparison test (limit or direct) for these types of series.

11. Sequences and Series

11.9. Representations of Functions as Power Series

11.9 Learning Objectives

  • Use the idea of geometric series to write functions as power series
  • Find the derivative and integral of power series
  • Use derivatives and integrals to find power series of more complex functions

11.9.1. Motivation

The short story is Polynomials Rule! Other functions drool! But read on for a few more details.

In practical applications, polynomials are our favorite type of functions.

  • To derive/integrate them it is just power rule (one of the easier rules for both),
  • Plugging numbers into polynomials is way easier than into other functions (can you tell me what sin(3) is without a calculator? can you tell me what 32+4⋅3+5 is without a calculator?),
  • Graphing polynomials is something a precalc class spends a lot of time on so it is something we consider easy at this point but other functions have other rules and are harder to deal with,
  • (Getting into the gory details) Evaluating (in a computer) polynomials is possible using additions and multiplications, but evaluating other functions is not (they just use what we are about to discuss…approximations!),
  • The domain of polynomials is all real numbers,
  • Polynomials just have a lot of great properties that we often wish other functions had…

Since power series resemble polynomials, if we can represent certain functions we know as power series, a world of possibilities opens up.

Eventually (11.11 or other application based classes) we use an approximation (sum only to 𝑁 instead of ∞) of the power series of a function in place of the actual function. This is how your calculator knows what sin(3) is!

11.9.2. Jumping off from Geometric Series

Recall for a geometric series we can write either

∑𝑛=1∞𝑎𝑟𝑛−1 or ∑𝑛=0∞𝑎𝑟𝑛,

and for a convergent geometric series the sum is exactly

∑𝑛=0∞𝑎𝑟𝑛=𝑎1−𝑟

.

Solution

∑𝑛=0∞𝑥𝑛

is like a geometric series with 𝑎=1 and 𝑟=𝑥. Geometric series converge when |𝑟|<1, so we need |𝑥|<1 for this to converge.

We can double-check that for 𝑥=±1 that the series diverges using the divergence theorem, since lim𝑛→∞(±1)𝑛≠0. This means we won’t need to check endpoints when we use the geometric series test to find the interval of convergence for power series!

Then, when |𝑥|<1 and the series converges, we know that

∑𝑛=0∞𝑥𝑛=𝑎1−𝑟=11−𝑥

This is an important result! Let’s write this as a theorem to reference later.

Make a flash card or remember the above! This will be the basis for all of our ideas in 11.9!

We will use this fact to help us build up power series representations of other functions like in the following example.

Solution

We need to write this function as something that looks like 11−𝑢 to use the theorem above. Notice, we specifically need to be subtracting something in the denominator, so

11+𝑥2=11−(−𝑥2)

Then, the thing we are subtracting gets plugged into the power series representation of the function, so

11+𝑥2=11−(−𝑥2)=∑𝑛=0∞(−𝑥2)𝑛

We can rewrite this as ∑𝑛=0∞(−1)𝑛𝑥2𝑛 if we want. Looking at ∑𝑛=0∞(−𝑥2)𝑛 it is easier to see that by the geometric series test we need |−𝑥2|<1.

|−𝑥2|<1⇒−1<𝑥<1

The interval of convergence is (−1,1), and we don’t need to check endpoints because we used geometric series test.

Solution

We can write

𝑥42𝑥−3=𝑥4⋅12𝑥−3=𝑥4⋅1−3(1−23𝑥)=−𝑥43⋅11−23𝑥

Which this has a 11−𝑢 type term now, where 𝑢=23𝑥.

We can turn the 11−𝑢 part into a series,

𝑥42𝑥−3=−𝑥43⋅11−23𝑥=−𝑥43⋅∑𝑛=0∞(23𝑥)𝑛

This is not yet a power series (need to “distribute” the −𝑥43 into the sum still) this is where we take a second to talk about the interval of convergence since it is the 𝑢𝑛 step. For geometric series, this converges when |𝑟|=|23𝑥|<1⇒|𝑥|<32. The radius of convergence is 𝑅=32, and since the series is centered at 0, the interval of convergence is (−32,32).

Continuing on with writing the power series,

𝑥42𝑥−3=−𝑥43⋅∑𝑛=0∞(23𝑥)𝑛=∑𝑛=0∞−2𝑛3𝑛𝑥𝑛𝑥43=∑𝑛=0∞−2𝑛3𝑛+1𝑥𝑛+4

If you want, skip this next note, but it is one of the reasons we have been doing all of chapter 11, so you may be interested. You don’t need to know any of this stuff, but it may spark some more interest in the world of computational mathematics :)

Note

Tiny application side tangent, at this point if you have a function 𝑓(𝑥)=𝑥42𝑥−3 and you want to evaluate it in the interval (−32,32), that the power series ∑𝑛=0∞−2𝑛3𝑛+1𝑥𝑛+4 can be used in its place. In a practical application, you truncate this sum taking just the 𝑁th partial sum to do so, and get an approximation.

Why would you do this instead of just using the original function? Well, if you are trying to evaluate 𝑓(𝑥)=𝑥42𝑥−3 near 32 (but just smaller than it), then the denominator here is very small. In the computer, this is like trying to divide by zero and any computational errors start to build up a lot on this step (Not to mention that division is a much more “expensive” operation in computers). All of the operations in the power series can be turned into multiplication and addition/subtraction (3 in the denominator would by multiplication by 0.333 etc). This saves time (division takes longer than other operation) and is more accurate (when done right) and makes some functions possible to evaluate on a computer (we will be able to write arctan(𝑥) as a power series by the end of section 11.9).

End side tangent, but this stuff is very cool and incredibly applicable to most sciences/engineering.

11.9.3. Differentiation and Integration of Power Series

Remember how taking derivatives and antiderivatives of polynomials is super easy? Well the same is true for power series, it’s all power rule!

Finally, we have a way to make every Calc 1 student’s dream come true: everything is always power rule!

Solution

Note that 𝑓(𝑥)=𝑐0+𝑐1(𝑥−𝑎)+𝑐2(𝑥−𝑎)2+… is differentiable on the interval (𝑎−𝑅,𝑎+𝑅) and

𝑓(𝑥)=𝑐0+𝑐1(𝑥−𝑎)+𝑐2(𝑥−𝑎)2+…𝑓′(𝑥)=0+𝑐1+2𝑐2(𝑥−𝑎)+3𝑐3(𝑥−𝑎)2+…=∑𝑛=1∞𝑛𝑐𝑛(𝑥−𝑎)𝑛−1=∑𝑛=0∞dd𝑥(𝑐𝑛(𝑥−𝑎)𝑛)

This is sometimes called term-by-term differentiation.

Solution

Note that 𝑓(𝑥)=𝑐0+𝑐1(𝑥−𝑎)+𝑐2(𝑥−𝑎)2+… is differentiable (and thus continuous and so integrable) on the interval (𝑎−𝑅,𝑎+𝑅) and

𝑓(𝑥)=𝑐0+𝑐1(𝑥−𝑎)+𝑐2(𝑥−𝑎)2+…∫𝑓(𝑥)d𝑥=𝐶+𝑐0(𝑥−𝑎)+𝑐1(𝑥−𝑎)22+𝑐2(𝑥−𝑎)33+…=𝐶+∑𝑛=0∞𝑐𝑛(𝑥−𝑎)𝑛+1𝑛+1=𝐶+∑𝑛=0∞∫𝑐𝑛(𝑥−𝑎)𝑛d𝑥

This is sometimes called term-by-term integration.

Again, these are important results that we don’t want to re-derive so we will write them as a theorem.

How do we find 𝐶 when we integrate a power series?
To find 𝐶, we evaluate

∫𝑓(𝑥)d𝑥=𝐶+∑𝑛=0∞∫𝑐𝑛(𝑥−𝑎)𝑛d𝑥

at 𝑥=𝑎 and solve for 𝐶.

Solution

Notice dd𝑥(11−𝑥)=1(1−𝑥)2, then using 11−𝑥=∑𝑛=0∞𝑥𝑛 we have

1(1−𝑥)2=dd𝑥(11−𝑥)=dd𝑥(∑𝑛=0∞𝑥𝑛)=∑𝑛=0∞dd𝑥(𝑥𝑛)=dd𝑥(1+𝑥+𝑥2+𝑥3+…)=0+1+2𝑥+3𝑥2+… notice that the 0th term has gone away=∑𝑛=1∞𝑛𝑥𝑛−1

Since we like to write power series starting at 𝑛=0, we can shift everything to

∑𝑛=1∞𝑛𝑥𝑛−1=∑𝑛=0∞(𝑛+1)𝑥𝑛

for our final answer.

This is kind of like a geometric series with |𝑟|=|𝑥|<1, so the radius of convergence is 𝑅=1. It is centered at 𝑎=0, so the interval is (−1,1).

(Note, we did not need to check the endpoints because it is geometric. If you had to find the radius of convergence with root or ratio test etc, then you would need to check the endpoints.)
